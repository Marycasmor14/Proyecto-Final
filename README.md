# AutoRep

AutoRep es una página web desarrollada como proyecto escolar, enfocada en la presentación de una empresa ficticia dedicada a la venta de refacciones automotrices y servicios mecánicos.

El sitio cuenta con diferentes secciones que permiten mostrar información de la empresa, catálogo de productos y datos de contacto de forma clara, organizada y visualmente atractiva.

# Características principales

- Página de inicio con presentación de la empresa
- Sección de productos con catálogo dinámico (20 productos)
- Visualización de productos con ventana emergente (modal)
- Diseño moderno con estilo oscuro y texto en rojo
- Sección de contacto con redes sociales
- Navegación entre diferentes páginas del sitio
- Diseño responsivo básico adaptable a diferentes pantallas
